# Publication notes

The supplied archive contained two Spanish Word reports, SSH private and public key files, and an exported virtual machine. Only the Word reports were extracted for review. The key files and VM were not extracted or published.

The public Spanish text comes from `Linux_Server_Hardening_Estilo_Unificado.docx`; the earlier `Documentacion.docx` was checked for context. Original Word packages are excluded to avoid publishing metadata and unreviewed embedded images. Local server/client addresses, host identifiers and user paths have been replaced with placeholders. The generic lab account `sysadmin` and documentation test address `192.0.2.10` are retained because they explain the configuration.

Five original screenshots were cropped to retain relevant results and remove host prompts and personal paths. No public/private SSH key, fingerprint, randomart, password, token, VM image or original archive is included. Screenshots that contain authorized-key material, network addresses or machine identifiers were excluded.

No server commands were executed as part of preparing this repository. The results describe the supplied lab evidence. The reproduction guide is documentation, not an automation script or a claim that this lab was rerun.
