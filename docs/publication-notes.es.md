# Notas de publicación

[English](publication-notes.md) · **Español**

El archivo suministrado contenía dos informes Word en español, archivos de claves SSH privada y pública y una máquina virtual exportada. Solo se extrajeron los documentos Word para revisarlos. Las claves y la máquina virtual no se extrajeron ni se publicaron.

El texto público en español procede de `Linux_Server_Hardening_Estilo_Unificado.docx`; se consultó también `Documentacion.docx` como contexto. Los documentos Word originales se excluyeron para evitar publicar metadatos e imágenes incrustadas sin revisar. Se sustituyeron las direcciones del servidor y del cliente, los identificadores de equipo y las rutas de usuario por marcadores. Se conservan la cuenta genérica `sysadmin` y la dirección de prueba para documentación `192.0.2.10` porque explican la configuración.

Se recortaron cinco capturas originales para conservar los resultados pertinentes y eliminar los indicadores de terminal con nombres de equipo y las rutas personales. No se incluyen claves SSH públicas o privadas, huellas de claves, representaciones randomart, contraseñas, tokens, imágenes de máquinas virtuales ni el archivo original. Se excluyeron las capturas que mostraban claves autorizadas, direcciones de red o identificadores de máquina.

No se ejecutaron comandos en un servidor al preparar este repositorio. Los resultados describen las evidencias del laboratorio suministradas. La guía de reproducción es documentación, no un script de automatización ni una afirmación de que se haya repetido el laboratorio.
